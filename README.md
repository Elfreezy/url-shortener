# URL Shortener

Небольшой сервис для сокращения ссылок: принимает длинный URL и возвращает короткий, а также делает редирект по короткому коду на исходный адрес.

## Стек
- Python 3.12+
- FastAPI
- Uvicorn
- sqlite3 (без ORM)
- pytest
- loguru


## Установка и запуск

1. Клонирование репозитория
```
git clone https://github.com/Elfreezy/url-shortener.git
cd url-shortener
```

2. Создание виртуального окружения
```
python -m venv .venv
source .venv/bin/activate  # Linux / macOS
# или
.venv\Scripts\activate     # Windows
```

3. Установка зависимостей
```
pip install -r requirements.txt
```
4. Запуск
```
uvicorn main:app
```

По умолчанию приложение будет доступно по адресу:

- API: http://localhost:8000
- Swagger UI: http://localhost:8000/docs <- лучше использовать при тестировании
- ReDoc: http://localhost:8000/redoc


## API

1. POST `/shorten` - cоздаёт сокращённую ссылку + записывает в БД.

Тело запроса (JSON):
```
{
  "url": "https://example.com"
}
```

Ответ 201 Created (JSON):
```
{
  "short_url": ""https://clck.ru/9ZAzq""
}
```

Возможные статусы:
| Сценарий                         | Статус | Описание                                           |
| -------------------------------- | ------ | -------------------------------------------------- |
| Успешное создание ссылки         | 201    | Ссылка создана, возвращён короткий URL             |
| Невалидный или пустой URL        | 400    | Некорректные данные клиента (если сам валидируешь) |

2. GET `/links` - возвращает массив сгенерированных кодов из БД.

Ответ (JSON):
```
[
  {
    "id": 1,
    "code": "F7DsK",
    "original_url": "https://habr.com/ru/",
    "short_url": "https://clck.ru/F7DsK",
    "created_at": "2026-02-11 19:05:27",
    "updated_at": null
  },
  {
    "id": 2,
    "code": "9ZAzq",
    "original_url": "https://music.yandex.ru/",
    "short_url": "https://clck.ru/9ZAzq",
    "created_at": "2026-02-11 19:05:55",
    "updated_at": null
  }
]
```

3. GET `/{code}` - редирект по короткому URL, где code - строка, сгенерированная при создании ссылки.

Возможные статусы:
| Сценарий                        | Статус | Описание                                     |
| ------------------------------- | ------ | -------------------------------------------- |
| Успешный редирект               | 302    | Временный редирект на исходный URL           |
| Код не найден                   | 404    | Сокращённая ссылка с таким кодом отсутствует |


4. GET `/links/delete/{code}` - удаляет запрашиваемый по коду объект из БД.

## Логирование и тестирование

Приложение использует loguru для вывода информации в командную строку (можно настроить на файл). Покрываются события-исключения и работа с БД. 

Тестирование покрывает функциональность класса `Service` реализующего бизнес-логику.
